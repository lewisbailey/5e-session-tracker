Public-edition limits

The public build deliberately excludes the full Aurora spell, item, feature and creature databases. Names and statistics visible after importing a character come from the file selected by the user and are processed locally.

Privacy

The tracker has no account or server database. Character state is stored in the browser on this device. Imported character files are processed locally and are not uploaded by this application.
